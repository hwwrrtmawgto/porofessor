## Overview

Porofessor is a League of Legends companion app providing real-time champion analytics — win rates, counter picks, optimal item builds, and summoner spell recommendations — as an overlay that activates automatically in champion select. It also tracks teammates' and opponents' historical performance to help with in-game strategy.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Porofessor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Champ Select Overlay** | Live champion stats and counter information during ban/pick phase |
| **Win Rate Data** | Current-patch win rates and optimal builds sourced from OP.GG data |
| **Summoner History** | View opponents' recent champion performance and win streaks |
| **Item Recommendations** | Patch-current item build paths for every champion and role |
